# Samsung Remote — бесплатная облачная сборка

Прототип нативного iOS-пульта для Samsung UE43T5202AUXRU. IP по умолчанию: 192.168.0.101. Протокол: Samsung Remote WebSocket, порт 8002. Код и команды **не проверены на реальном ТВ**.

## Сборка через GitHub Actions (без Xcode на Mac)

1. На GitHub создайте новый **private** репозиторий `SamsungRemote-iOS` (бесплатная квота Actions для приватных репозиториев ограничена).
2. Распакуйте архив на Mac. В репозитории нажмите **Add file → Upload files** и загрузите `project.yml`, папку `SamsungRemote` и `.github/workflows/build-ios.yml`. Важно: Finder скрывает `.github`; включите отображение скрытых файлов клавишами Cmd+Shift+точка. Альтернатива — загрузить через git в Terminal.
3. Если загрузка папки `.github` через веб-интерфейс не удалась, откройте **Add file → Create new file**, введите `.github/workflows/build-ios.yml` и скопируйте содержимое из архива.
4. Откройте **Actions → Build Samsung Remote IPA → Run workflow** (или дождитесь запуска после push). Сборка на macOS runner может занять несколько минут.
5. В успешном запуске скачайте artifact `SamsungRemote-unsigned-IPA` и распакуйте ZIP. Внутри будет `SamsungRemote-unsigned.ipa`.

## Установка бесплатно

6. Установите Sideloadly с https://sideloadly.io/ на Mac. Проверьте поддержку вашей macOS и iOS на официальном сайте.
7. Подключите iPhone кабелем, подтвердите доверие, выберите его в Sideloadly и укажите unsigned IPA. Для подписи используется бесплатный Apple ID; НЕ загружайте пароль Apple ID в GitHub или Actions.
8. На iPhone при необходимости включите Developer Mode и доверьте профиль разработчика в настройках VPN и управления устройством.
9. iPhone и Samsung должны быть в одной Wi-Fi сети. Откройте приложение, разрешите локальную сеть, подключитесь к `192.168.0.101` и подтвердите запрос на ТВ.

## Ограничения

- Бесплатная подпись обычно действует 7 дней, после чего нужна повторная установка/обновление подписи.
- Неподписанный IPA **не устанавливается напрямую**: Sideloadly подписывает его при установке.
- Совместимость Sideloadly с iOS 26.3 и конкретным устройством нужно проверить; возможны изменения Apple.
- Команды `KEY_SMART_HUB` и `KEY_MENU` могут не поддерживаться телевизором; `KEY_HOME` может дублировать Smart Hub.
- Телевизор может сменить IP после перезапуска роутера.
- Самоподписанный сертификат ТВ принимается только для введённого локального IP; это компромисс для домашнего прототипа.
- При ошибке сборки скачайте логи Actions и пришлите текст ошибки.
